# Vinamah

**[Vinamah](https://vinamah.com)** is an Omegle-style networking platform built specifically for professionals — real one-to-one conversations instead of posts, likes, and algorithms. Only verified users can join.

This repo (`techconnect-live`) is the code behind it: a live, random-match video/chat app that pairs tech professionals for a real-time conversation instead of a feed.

## What it does

- Randomly matches two verified professionals for a live one-on-one conversation.
- No posting, no likes, no algorithmic feed — just a real-time connection.
- Built for people who want to network the way you'd meet someone at a conference, not scroll past them.

## Project layout

- `omegele-frontend/` — the frontend for the matching/video experience.
- `PLANNING.md` — original project planning notes.
- `MATCH_IMPLEMENTATION_PLAN.md` — notes on how the random-match logic was implemented.
